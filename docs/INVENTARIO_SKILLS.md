## Alcance y lectura

Se inspeccionaron los SKILL.md presentes en .agents/skills/ del proyecto y en las rutas host .codex/skills/, .agents/skills/, .codex/plugins/cache/openai-bundled/, .codex/plugins/cache/openai-primary-runtime/ y .codex/plugins/cache/openai-curated-remote/. La fecha `last-updated` de una Skill no demuestra cuándo se instaló en esta máquina.
